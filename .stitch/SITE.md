# LSWOO Middleware Admin GUI - Site Vision

## Vision
A premium, mission-critical administrative console for managing the synchronization between Lightspeed Retail (X-Series) and WooCommerce. The interface must feel like a modern, high-performance toolkit—sleek, fast, and informative.

## Technical Goals
- Replace basic EJS templates with a premium design system.
- Maintain monolithic Express/EJS delivery but with modern component-based UI.
- Ensure visual consistency across Dashboard, Products, and Logs.
