# LSWOO Admin Design System

## 1. Core Palette
- **Primary**: Deep Forest Green (`#064e3b`) - represents stability and "Go" state.
- **Surface**: Off-white / light gray (`#f9fafb`) with subtle borders.
- **Accents**: Neon Green for sync activity, Slate for structure.

## 2. Typography
- **Headings**: Inter / Sans-serif, bold, tight-tracking.
- **Body**: System sans-serif, clean, high readability.

## 3. UI Tokens
- **Roundness**: `ROUND_EIGHT`
- **Saturation**: High
- **Color Mode**: `LIGHT`

## 4. Stitch Generation Notes
When generating screens, use a "glassmorphism" approach for cards. Use subtle shadows and large, clear typography for health status.
