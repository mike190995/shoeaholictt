Generate a high-performance administrative dashboard for a middleware platform named LSWOO. 

**Core Components Needed:**
1. **System Health Widgets**: Cards showing "Lightspeed Connection", "WooCommerce Connection", "Cloud Tasks Queue", and "Redis Status". Use status indicators (Green/Red).
2. **Metrics Grid**: Large numbers for "Total Products Synced", "Pending Tasks", and "Errors (24h)".
3. **Recent Activity Table**: A sleek table showing the last 5 sync events with timestamps, direction (LS -> Woo), and status tags.
4. **Header**: LSWOO logo, user profile, and global search.
5. **Sidebar**: Links to Dashboard, Products, Sync Logs, and Settings.

**DESIGN SYSTEM (REQUIRED):**
- Primary Color: Deep Forest Green (#064e3b)
- Secondary Color: Slate Gray (#64748b)
- Layout: Modern grid system with subtle shadows and rounded corners (ROUND_EIGHT).
- Aesthetic: Clean, glassmorphism-lite, readable data tables.
